# A/B 테스트 리포트 — 추천 전략 비교

평가 프로토콜은 [`01_실험_프로토콜.md`](01_실험_프로토콜.md) 참조. 통계 검정은 `random_seed=42`, 동일 평가셋 기준.

---

## 1. 목적

서로 다른 두 추천 전략의 성과 차이가 **통계적으로 유의한지**를 검정한다. 명세 요구에 따라 Chi-square 검정과 2-비율 Z-검정을 수행하고 p-value 와 95% 신뢰구간을 제시한다.

---

## 2. 실험 설계

| 항목 | 내용 |
|---|---|
| **그룹 A (Control)** | 인기도 기반 추천 — train 구매 상위 50개를 전 유저에 동일 추천 (비개인화) |
| **그룹 B (Treatment)** | Multi-Stage 개인화 추천 — Two-Tower → DeepFM → 재랭킹 |
| **표본** | `test_logs.csv` 구매 이벤트에서 추출한 평가 샘플 500건 (그룹별 동일) |
| **전환 정의** | 추천 Top-50 안에 해당 유저의 **실제(test) 구매 상품**이 포함되면 "전환" (HitRate@50 기반 오프라인 카운터팩추얼 전환) |
| **검정** | Chi-square (2×2) + 2-비율 Z-검정, 유의수준 α = 0.05 |

> 시뮬레이터 기반 오프라인 환경이므로, 라이브 클릭 트래픽 대신 **"추천이 유저의 실제 구매를 포착했는가"** 를 전환 프록시로 사용한다. 두 전략을 동일 표본에 적용해 비교하는 카운터팩추얼 A/B 방식이다.

---

## 3. 결과

### 분할표 (Contingency Table)

| 그룹 | 전환 | 비전환 | 합계 | 전환율(CVR) |
|---|---|---|---|---|
| A · 인기도 (Control) | 1 | 499 | 500 | **0.20%** |
| B · Multi-Stage (Treatment) | 185 | 315 | 500 | **37.00%** |

### 통계 검정

| 항목 | 값 |
|---|---|
| Chi-square 통계량 (dof=1) | **223.61** |
| Z 통계량 (2-비율 검정) | **14.95** |
| **p-value** | **< 0.001** (유의수준 0.05 에서 매우 유의) |
| 전환율 차이 (B − A) | +36.80%p |
| **95% 신뢰구간 (B − A)** | **[ +32.55%p, +41.05%p ]** |
| Lift (B / A) | 약 184배 |

---

## 4. 해석

- p-value 가 0.001 을 크게 밑돌아, 두 전략의 전환율 차이는 **우연으로 설명되지 않는다**. Multi-Stage 개인화 추천(B)이 인기도 추천(A) 대비 통계적으로 유의하게 우월하다.
- 95% 신뢰구간이 0 을 포함하지 않고 전 구간이 양수([+32.55%p, +41.05%p]) — 개선 효과의 방향과 크기가 안정적으로 확인된다.
- Control 의 전환율이 0.2% 로 극히 낮은 것은, 본 시뮬레이터가 유저마다 좁은 개인 상품 풀을 갖도록 설계되어 **전역 인기 상품이 개별 유저의 관심사와 거의 겹치지 않기** 때문이다. 이는 비개인화 전략의 한계와 개인화의 가치를 동시에 보여준다.

---

## 5. A/B 테스트 대시보드 (실시간 검정 엔진)

`phase4_dashboard.py` (http://localhost:8501, Tab 3) 는 임의의 두 전환율에 대한 통계 검정을 실시간 제공한다:

- Chi-square 검정 + 2-비율 Z-검정, p-value 산출
- 95% 신뢰구간 (정규 근사)
- 검정력(Power) 분석 — 목표 검출력 80% 기준 최소 표본 수 계산
- 실시간 로그(`new_train_logs.csv`) 및 CT 아카이브 CVR 자동 채우기

이를 통해 평가자는 표본 수·전환율을 바꿔가며 통계적 유의성을 직접 검증할 수 있다.

---

## 6. 결론

- 추천 전략 A(인기도) vs B(Multi-Stage 개인화) 비교에서 B 의 우월성이 **Chi-square·Z-검정 모두 p < 0.001 로 통계적으로 입증**되었다.
- 95% 신뢰구간 [+32.55%p, +41.05%p] 로 효과 크기가 안정적이다.
- 대시보드가 실시간 A/B 검정·검정력 분석 기능을 제공하여 추가 실험이 가능하다.
